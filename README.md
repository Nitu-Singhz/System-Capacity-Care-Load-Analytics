# System Capacity & Care Load Analytics for Unaccompanied Children

## Project Overview

This project focuses on analyzing reported care workload trends across the **U.S. Customs and Border Protection (CBP)** and the **Department of Health and Human Services (HHS)** from 2023 to 2025.

The objective is to understand changes in system workload, custody trends, transfers, apprehensions, and discharges through data analysis and interactive visualizations.

The project was completed as part of my **Data Analytics Internship at Unified Mentor**.

## Project Objectives

- Analyze reported system workload trends between 2023 and 2025.
- Examine CBP custody and HHS care patterns.
- Understand trends in apprehensions, transfers, and discharges.
- Identify important patterns through exploratory data analysis.
- Develop an interactive dashboard to communicate analytical findings.

1. Data loading and inspection.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. KPI calculation and trend analysis.
5. Interactive charts and visualizations.
6. Streamlit dashboard development.
7. Deployment using Streamlit Community Cloud.

## Dashboard Features

- Six KPI cards providing an overview of system workload.
- Interactive date filters.
- Multiple data granularity options.
- Charts for exploring workload and movement trends.
- Data Explorer for examining underlying records.
- Insights and Methodology section explaining findings and analytical limitations.

## Key Analytical Considerations

- The dataset contains irregular reporting dates; missing dates are not treated as zero values.
- CBP custody and HHS care represent stock measures, while apprehensions, transfers, and discharges represent flows.
- Transfers between CBP and HHS are internal system movements and should not be counted as additional children in total system load.
- The analysis uses workload indicators and pressure proxies. It does not directly measure facility capacity, overcrowding, or staffing availability.
